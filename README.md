# React + TypeScript + Vite

## PATRON DE COMPONENTES COMPUESTO (Compound Components Pattern)

Es un Patrón de diseño que permite crear componentes complejos y reutilizables mediante la composición de componentes más simple. Su estructura consta de:

- `Componente padre: ` gestiona el estado y la lógica centralizada.

- `Componente hijo: ` interactuan con el estado a partir de un contexto o API común.

- `Context o API: ` para compartir el estado o la lógica entre los componentes.
